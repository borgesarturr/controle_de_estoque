# 📦 Controle de Estoque

Este é um sistema simples desenvolvido em Python para gerenciamento e controle de estoque de produtos, utilizando o banco de dados SQLite.

## 🚀 Funcionalidades
* Cadastro de novos produtos no estoque.
* Consulta e busca de itens cadastrados.
* Registro automático de movimentações (Logs).
* Inicialização automática do banco de dados.

## 🛠️ Tecnologias Utilizadas
* **Python 3**
* **SQLite** (Banco de dados integrado)

## 💻 Como Executar o Projeto
1. Certifique-se de ter o Python instalado na sua máquina.
2. Abra o terminal na pasta do projeto.
3. Execute o comando:
   ```bash
   python app.py
   ```
